Projeto simples demonstrando como **trocar uma imagem colorida por uma versão preto e branca quando o usuário passa o mouse**.  
Feito apenas com **HTML** e **JavaScript**, sem CSS externo.

🔗 **Demo online:**  
https://luizrogeriopx.github.io/BotoesHTML5/

---

## 🧠 Sobre o projeto

Este projeto apresenta uma técnica simples e eficiente para criar efeitos visuais em imagens usando apenas **JavaScript**:

- Ao passar o mouse: imagem muda para versão **preto e branca**  
- Ao retirar o mouse: volta para **colorida**

Excelente para quem está aprendendo efeitos visuais básicos com HTML e JS.
